# プロダクト要求定義書 — きょうのやること（小学生向けタスク管理アプリ）

## 1. 背景

小学生には「しゅくだい」「おてつだい」「あしたのじゅんび」など、毎日やることがたくさんある。
しかし、何をするかは大人から口で伝えられることが多く、子どもが自分で全体を見わたしたり、
終わったことを確かめたりする手段がない。

### 困りごと

| # | 困りごと | 状況 |
|---|---|---|
| B-1 | 言われるまでやらない | 何をするかを子どもが自分で把握していない |
| B-2 | やったかどうか覚えていない | 終わったことを確かめる手段がない |
| B-3 | 保護者が毎日声をかけて疲れる | 「しゅくだいやった？」の確認を毎日くりかえしている |
| B-4 | やりたいことを先にやり、やらなきゃいけないことができない | ゲームや動画など遊びを先に始めてしまい、しゅくだいやじゅんびが後回しになって終わらない |
| B-5 | 寝る時間のルールを守れない | 後回しにしたやることや遊びで時間が押し、決めた寝る時間をすぎてしまう |

## 2. 目的

大人に言われてやるのではなく、**自分で見て・自分でチェックして・ほめられる** 体験をつくり、
生活習慣と自己管理の力を育てる。

| # | 目的 | 具体的な状態 |
|---|---|---|
| P-1 | やることを自分で把握できる | きょう何をすればよいか、子どもが一人でアプリを見てわかる |
| P-2 | 自分で完了を記録できる | 終わったことを子ども自身が「できた」とチェックする |
| P-3 | 達成感を得て続けられる | ⭐やお祝いの演出でほめられ、毎日使いたくなる |
| P-4 | 保護者の声かけを減らす | 「しゅくだいやった？」と毎日聞かなくても、アプリで状況がわかる |
| P-5 | やらなきゃいけないことを先に終わらせる | やることが終わってから、やりたいことをする順番が身につく |
| P-6 | 寝る時間を守る | 寝る時間から逆算して、いつまでに何を終わらせればよいかがわかり、決めた時間に寝られる |

| 困りごと | 対応する目的 |
|---|---|
| B-1 言われるまでやらない | P-1 |
| B-2 やったかどうか覚えていない | P-2 |
| B-3 保護者が毎日声をかけて疲れる | P-4 |
| B-4 やりたいことを先にやってしまう | P-5, P-3 |
| B-5 寝る時間のルールを守れない | P-6 |

## 3. 対象ユーザー

| ペルソナ | 説明 | 主なニーズ |
|---|---|---|
| 子ども（主ユーザー） | 小学1〜6年生。低学年は漢字がほぼ読めない | きょう何をするか一目でわかる／タップでかんたんに「できた」にできる／がんばりが見える |
| 保護者（副ユーザー） | タスクの登録を手伝う | 毎日・曜日ごとのくりかえしを一度だけ設定したい |

## 4. 利用環境

- 家庭のタブレット・PC・スマートフォンのブラウザ（Chrome / Edge / Safari 最新版）
- 1台の端末を1人の子どもが使う想定（アカウント・ログインなし）
- オフラインでも動作すること（データは端末内に保存）

## 5. 機能要求（MVP）

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-01 | きょうのやること表示 | きょう予定されているやることを大きなカードで一覧表示する | 必須 |
| F-02 | できたチェック | カードをタップすると「できた」になり、ほし⭐が1つもらえる。もう一度タップで取り消せる | 必須 |
| F-03 | やることの追加 | なまえ・アイコン（絵文字）・しゅるい・くりかえしを指定して追加する | 必須 |
| F-04 | くりかえし設定 | 「まいにち」「ようびをえらぶ」「いちどだけ（日付指定）」の3種類 | 必須 |
| F-05 | やることの編集・削除 | 登録済みのやることを変更・削除する（削除は確認あり） | 必須 |
| F-06 | ほしの合計表示 | これまでにもらったほしの合計を常に表示する | 必須 |
| F-07 | ぜんぶできた演出 | きょうのやることがすべて完了したら、お祝いのアニメーションを表示する | 必須 |
| F-08 | がんばりきろく | 直近7日間の「できた数／予定数」をスタンプ形式で表示する | 推奨 |
| F-09 | まだのやること持ち越し | 「いちどだけ」のやることは、できるまで翌日以降も表示する | 推奨 |

#### P-5 やらなきゃいけないことを先に終わらせる

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-10 | やりたいことの登録 | ゲーム・動画・あそびなどを「やりたいこと」として登録できる（追加・編集・削除は F-03〜F-05 と同じ） | 必須 |
| F-11 | じゅんばん表示 | きょうの画面を「① やること」→「② やりたいこと」の2段に分け、やることを上に表示する | 必須 |
| F-12 | やりたいことのカギ | やることがすべて「できた」になるまで、やりたいことは🔒表示にしてチェックできない | 必須 |
| F-13 | カギがあく演出 | やることがすべて終わったら🔓「やりたいことをしていいよ！」と表示する | 必須 |

#### P-6 寝る時間を守る

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-14 | 寝る時間の設定 | 寝る時間を曜日ごとに設定できる（既定 21:00） | 必須 |
| F-15 | ねるまでのこり時間 | きょうの画面に「ねるまで あと ○じかん○ぷん」を表示する | 必須 |
| F-16 | なんじまでに | やることに「なんじまでに」を任意で設定できる。未設定のやることは寝る時間がしめきりになる | 必須 |
| F-17 | しめきりが近い表示 | しめきり30分前から「もうすぐ」、すぎたら「じかんすぎたよ」と色とアイコンで知らせる | 必須 |
| F-18 | ねるじゅんびモード | 寝る時間の30分前になったら画面を「ねるじゅんび」に切り替え、やりたいことは「またあした」と表示する | 推奨 |
| F-19 | ねるまでにできたきろく | がんばりきろく（F-08）に「寝る時間までにやることがぜんぶできた日」のスタンプを表示する | 推奨 |

> 注: アプリ（Web アプリ）は他のアプリやゲーム機そのものを止めることはできない。F-12 の「カギ」は、
> 子どもと保護者が決めたルール（やることが終わったら遊ぶ）を見える形にするものである。
> iPad では、次の F-20〜F-22 で iOS 標準の「ショートカット」アプリと連携し、他のアプリの利用を制限する。

#### P-5 補足: iPad の他のアプリの利用制限（ショートカット連携）

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-20 | かいほうの記録 | やることがすべて「できた」になったら、🔓表示（F-13）に「あそびにいく」ボタンを出す。押すと iOS ショートカットを呼び出し、「きょうはかいほう済み」を端末に記録する | 必須 |
| F-21 | 制限アプリを開いたときのチェック | 保護者が選んだアプリ（動画・ゲームなど）を開くと、ショートカットのオートメーションが記録を確認し、きょうかいほうされていなければこのアプリを開く | 必須 |
| F-22 | せっていガイド | ショートカットとスクリーンタイムの設定手順を、保護者向けにアプリ内で案内する | 推奨 |

> 制限の範囲: 制限できるのはオートメーションで選んだアプリだけで、iPad 全体ではない。
> 制限したアプリは一瞬表示されてから、このアプリに切り替わる。
> 子どもがショートカットを消したり変えたりできないよう、スクリーンタイムでショートカットアプリをパスコード付きで制限することを前提にする。
> 一度かいほうしたあとに「できた」を取り消しても、その日のかいほうは取り消されない（日付が変わると自動でカギがかかる）。

### 将来検討（MVP対象外）

- 保護者用ロック（PINで追加・削除を制限）
- 複数の子どもの切り替え
- ほしとごほうびの交換
- 通知・リマインダー（アプリを開いていないときの音・プッシュ通知）
- 端末間の同期
- ゲーム機の利用制限との連携（iPad のアプリ制限は F-20〜F-22 で対応）
- MDM による iPad 全体のロック（単一アプリモードの自動切り替え）

## 6. 非機能要求

| 分類 | 要求 |
|---|---|
| わかりやすさ | 画面の文言はひらがな中心。漢字を使う場合は低学年でも読めるものに限る。アイコンと色で意味が伝わる |
| 操作性 | タップ領域は最小 56px 四方。1画面1目的。主要操作は2タップ以内 |
| 安全性 | 外部通信を行わない。個人情報を収集しない。広告・外部リンクなし |
| 可用性 | ネット接続なしで動作する。ブラウザを閉じてもデータが残る（localStorage） |
| 堅牢性 | 保存データが壊れていてもアプリが起動できる（初期状態にフォールバック） |
| 性能 | 初回表示 1 秒以内（ローカル配信）。ビルド工程・外部ライブラリなし |
| アクセシビリティ | ボタンに読み上げ用ラベルを付与。色のみに依存しない。アニメーションは `prefers-reduced-motion` を尊重 |

## 7. 成功指標

- 子どもが保護者の手助けなしに「できた」チェックを行える
- 1週間のうち5日以上アプリを開いてチェックしている

## 8. 未決事項（要確認）

| # | 論点 | 現在の仮定 |
|---|---|---|
| Q1 | 対象学年 | 1〜6年生すべて（文言はひらがな中心で低学年に合わせる） |
| Q2 | タスクを登録するのは誰か | 子ども・保護者どちらも可。保護者ロックは MVP 対象外 |
| Q3 | 利用する子どもの人数 | 1端末1人。複数人切り替えは MVP 対象外 |
| Q4 | ごほうびの仕組み | ほし⭐を貯めるだけ。ごほうび交換は MVP 対象外 |
| Q5 | 提供形態 | ブラウザで動く Web アプリ、データは端末内保存、ネット通信なし |
| Q6 | 時間の扱い | 寝る時間と「なんじまでに」を分単位で扱う（F-14〜F-17）。時刻は端末の時計を使う |
| Q7 | 「やりたいこと」の扱い | やりたいことも登録し、やることが終わるまでカギをかける（F-10〜F-13） |
| Q8 | 寝る時間の設定 | 曜日ごとに設定できる。設定するのは保護者（ただし保護者ロックはないので子どもも変えられる） |
| Q9 | カギの強さ | やりたいことは完全にチェックできなくする（F-12）。保護者が一時的にカギをあける機能は持たない |
| Q10 | 時間の数値 | 「もうすぐ」はしめきり30分前、ねるじゅんびモードは寝る時間の30分前。設定で変えられるようにするか |
| Q11 | 寝る時間をすぎたあと | 日付が変わるまでは「きょう」として扱う。夜中0時をすぎて開いた場合の扱いは要検討 |
| Q12 | iPad の他のアプリの制限方法 | ネイティブ iOS アプリは作らない（Mac がなく、Screen Time API も使えないため）。ショートカット連携（F-20〜F-21）で、外部サーバーなしで実現する |
| Q13 | 寝る時間をすぎたあとのかいほう | ねるじゅんびモード（F-18）の間は「あそびにいく」ボタンを出さない |
